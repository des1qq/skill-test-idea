# business-idea-validator

Скилл для AI-агента (Qoder CLI и совместимых), который валидирует конкретную
бизнес-идею: исследует нишу, аудиторию, конкурентов, цены, тренды и риски
через веб-поиск, затем выдаёт структурированный отчёт с баллами по критериям
и явным вердиктом — запускать, изменить, протестировать или отказаться.

## Зачем это нужно

Обычный ответ ИИ на "оцени мою идею" часто выглядит убедительно, но
наполовину выдуман. Этот скилл заставляет агента:

1. сначала собрать у пользователя гео, стадию идеи, доступные ресурсы
   (бюджет/время/команда) и предпочтения по монетизации — без этого оценка
   "сложности реализации" и "доступности клиентов" получается абстрактной,
   не привязанной к конкретному человеку;
2. затем искать реальные данные о нише (факты), а не придумывать их;
3. явно отделять гипотезы и выводы от фактов;
4. честно писать "неизвестно", если данных не хватает;
5. заканчивать не оценкой "хорошо/плохо", а конкретным и реалистичным
   (с учётом ресурсов пользователя) решением.

## Установка

Скопируйте папку `business-idea-validator/` в директорию скиллов:

- Пользовательский уровень: `~/.qoder/skills/business-idea-validator/`
- Уровень проекта: `.qoder/skills/business-idea-validator/`

Перезапустите сессию или выполните `/skills reload`, затем проверьте
`/skills list`.

## Как использовать

Просто попросите агента (на русском или английском):

- «Оцени мою бизнес-идею: [описание]»
- «Проведи исследование ниши для [идея]»
- «Есть ли рынок для [продукт]?»
- «Сравни эту идею с конкурентами»
- «Проверь, стоит ли делать MVP для [идея]»
- «Найди слабые места моей концепции»
- "Validate my business idea: ..." / "Is there a market for ...?"

## Что на выходе

Структурированный отчёт в Markdown: итоговый балл перспективности, сильные
и слабые стороны, ключевые гипотезы, таблица конкурентных альтернатив,
баллы по 7 критериям (сила проблемы, платёжеспособность аудитории,
конкуренция, доступность первых клиентов, сложность реализации,
маржинальность, риски), конкретные шаги для проверки идеи и финальный
вердикт.

Полный формат отчёта и критерии оценки — в `references/report-template.md`
и `references/scoring-rubric.md`.

## Структура

```
business-idea-validator/
├── SKILL.md                       — инструкция и рабочий процесс для агента

```
